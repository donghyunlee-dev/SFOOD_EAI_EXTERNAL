## 📊 배치 프로세스

### 🔄 배치 실행 흐름
1. **⏱️ 스케줄링 (BatchScheduler)**
- Spring의 @Scheduled 어노테이션을 사용하여 배치 작업의 실행 주기 설정
- cron 표현식을 통해 정확한 실행 시간 지정 (예: "0 1 0 * * *" - 매일 자정 00:01분)
- 스케줄러는 BatchJobService를 호출하여 실제 배치 작업 실행


2. **🚀 배치 작업 서비스 (BatchJobService)**
- JobLauncher를 통해 Job을 실행
- JobParameters를 생성하여 배치 작업에 필요한 파라미터 전달
- 배치 작업의 실행 결과를 로깅하고 모니터링


3. **🏗️ 작업(Job) 생성**
- 각 배치 작업은 batch > job > Config 클래스에서 @Bean으로 등록된 Job을 사용  


- **🏭 Factory 패턴 적용**
    - JobFactory 인터페이스를 구현한 DefaultJobFactory가 모든 Job 빈을 Map으로 주입받음
    - Spring의 의존성 주입을 통해 모든 Job 빈이 자동으로 Map<String, Job>에 수집됨
    - 배치 작업 실행 시 JobFactory.getJob(jobName)을 통해 필요한 Job을 이름으로 조회


4. **⚙️ 배치 작업 처리 방식**
- **🧩 Tasklet 방식**: 단일 태스크로 처리되는 간단한 배치 작업
    - 한 번에 모든 처리를 수행하는 방식
    - 예: 메일 서비스, 데이터 초기화, 단순 집계 작업 등


  - **📦 Chunk 방식**: 대량의 데이터를 처리하는 복잡한 배치 작업
    - Reader, Processor, Writer의 3단계로 처리
    - Reader: 데이터 읽기 (ItemReader 인터페이스 구현)
    - Processor: 읽은 데이터 가공 (ItemProcessor 인터페이스 구현)
    - Writer: 가공된 데이터 저장 (ItemWriter 인터페이스 구현)
    - 트랜잭션 경계 내에서 청크 단위로 처리하여 메모리 효율성과 장애 복구 기능 제공

## 📋 배치 작업 설명
### 🔢 주문번호 시퀀스 생성
- 기능 설명   
  - 주문번호는 조합형으로 OR + 주문일자 + 연동몰코드 + 일련번호 구성으로 생성      
  - 뒷자리 일련번호의 동시성 문제를 해결하기 위해 시퀀스 테이블의 락을 이용해서 일련번호 중복 방지하여 사용   
  - 날짜가 변경됨에 따라 일자별 신규 시퀀스가 생성될 때 락이 안걸리는 문제를 해결하기 위해 배치 작업으로 초기 데이터 생성


- 배치 일정    
  - 🕐 매일 자정 00:01분


- 대상 테이블    
  - 💾 TBL_ORDER_SEQUENCE (주문일련번호)

### 📧 예외단가 만료 일자 메일 알림
- 기능 설명      
  - **사용 기간이 만료될 예정인 거래처의 예외단가 정보를 이메일로 발송하는 기능**   
  - 등록된 거래처, 거래처 그룹의 만료되기 7일전 예외 단가를 조회하여 담당자에게 리스트 전달   
  - 메일은 Thymeleaf 템플릿 기반 HTML 메일로 발송


- 조건   
  - ⏳ 예외단가 종료일(PRICING_END_DATE)이 배치일자로부터 1 ~ 7일이 남은 단가


- 배치 일정   
  - 🕗 일 ~ 금요일 08:00분


- 대상 테이블   
  - 💾 TBL_PRICING_EX_PARTNER (거래처예외단가)   
  - 💾 TBL_PRICING_EX_PARTNER_GROUP (거래처그룹예외단가)

### 🔒 자동 주문 마감
- 기능 설명   
  - **출고 완료된 주문 중 7일 이전 주문을 배치 작업으로 마감 처리하는 기능**   
  - 배송일자 기준으로 7일이 지난 모든 주문을 조회하여 주문 마감 데이터를 생성      
  - 이미 수동으로 마감이 되어 있는 경우에는 생성하지 않음.


- 조건
    1. 📋 주문상세정보(TBL_ORDER_GOODS)에서 주문상태코드(ORDER_STATUS_CODE)를 확인
        1. 주문상태 : 반품완료(OS5040), 교환완료(OS4040), 출고완료(OS2040)
    2. 🚚 주문배송정보(TBL_ORDER_DELIVERY)에서 배송시작일(START_DELV_DATE) 기준으로 일자 체크
    3. ✅ 주문 마감(TBL_ORDER_CLOSE_INFO)이 되지 않은 주문인지 확인



- 배치 일정   
  - 🕐 매일 자정 00:01분


- 대상 테이블   
  - 💾 TBL_ORDER_CLOSE_INFO (주문 마감 정보)
