# 클레임 주문 처리 방식 정의

## 개요 
> 이 문서는 고도몰 주문 수집 시 발생하는 클레임(취소/교환/반품/환불)에 대한 OMS 시스템의 처리 방식을 정의합니다.   
> 고도몰의 클레임 상태를 기준으로 API를 통해 주문을 수집하고 OMS에 저장된 원주문을 조회하여 각 클레임에 맞는 비즈니스 로직을 수행합니다.

### **1. 취소 (Cancellation)**

> '입금대기' 상태에서 고객의 직접적인 요청 또는 일정 기간 경과로 인해 주문이 취소되는 경우입니다.

**처리 대상 확인**   
- 취소된 고도몰의 주문번호로 OMS에서 원주문이 존재하는지 확인합니다.

**처리 제외 조건**
- 원주문이 존재하지 않는 경우 (물류와 무관하므로 처리 불필요)
- 원주문의 상태가 물류 진행 중이거나 이미 취소가 완료된 경우

**원주문 정보 업데이트**   
- 주문 상태를 `취소완료`로 변경합니다.   
- 취소 수량, 취소 사유(코드 및 상세 내용)를 업데이트합니다.  
- 해당 품목의 주문 금액, 공급가, 부가세를 `0`으로 업데이트합니다.  

**클레임 생성**  
- OMS 원주문의 품목에 대한 기존 클레임이 없는 경우, 신규 클레임 정보를 생성합니다.

**주문 상태 변경 이력 생성**  
- '입금대기' -> '취소완료'로 변경된 이력을 기록합니다.

---

### **2. 교환 (Exchange)**

> 배송이 완료된 다음 주문한 제품과 다르거나 잘못된 제품을 받았을 때 교환을 하는 경우입니다.   
> 고도몰에서는 교환접수를 진행하고 교환승인 및 교환완료는 OMS에서 진행합니다.

**처리 대상 확인**
- 교환접수한 고도몰의 주문번호로 OMS에서 원주문이 존재하는지 확인합니다.

**처리 제외 조건**
- 원주문이 존재하지 않는 경우
- 원주문의 상태가 이미 취소 완료된 경우 

**신규 주문 상세 생성**
- 교환 주문 상세(품목) 정보를 추가합니다.
- 주문 상태를 `교환요청`로 변경합니다.
- (-) 주문 수량과 (-) 주문 금액으로 변경합니다.
- 교환을 하는 제품의 원 주문 주문상세번호를 클레임 순번으로 저장합니다.

**클레임 생성**
- 추가된 교환 상세 정보의 신규 클레임 정보를 생성합니다.

**클레임 배송 정보 생성**
- 추가된 교환 상세 정보의 배송 정보를 추가합니다.
- 반품 요청일을 저장합니다.


### **3. 반품 (Return)**

> 배송이 완료된 다음 제품에 문제가 있거나 변심에 의해 반품할 경우입니다.  
> 반품은 전체 수량 반품과 일부 수량만 반품할 수 있습니다.

**처리 대상 확인**
- 반품접수한 고도몰의 주문번호로 OMS에서 원주문이 존재하는지 확인합니다.

**처리 제외 조건**
- 원주문이 존재하지 않는 경우
- 원주문의 상태가 `출고완료`가 아닌 경우

**신규 주문 상세 생성**
- 반품 주문 상세(품목) 정보를 추가합니다.
- 주문 상태를 `반품요청`으로 변경합니다.
- (-) 주문 수량과 (-) 주문 금액으로 변경합니다.
- 반품을 하는 제품의 원 주문 주문상세번호를 클레임 순번으로 저장합니다.

**클레임 생성**
- 추가된 반품 상세 정보의 신규 클레임 정보를 생성합니다.

**클레임 배송 정보 생성**
- 추가된 반품 상세 정보의 배송 정보를 추가합니다.
- 반품 요청일을 저장합니다.
---

### **4. 환불 (Refund)**

> 결제가 완료된 주문을 취소하는 경우입니다.  
> OMS에 따라 취소와 반품 2가지 경우에 따라 클레임 처리가 다릅니다.    
>
**처리 대상 확인**
- 반품접수한 고도몰의 주문번호로 OMS에서 원주문이 존재하는지 확인합니다.
  
**처리 제외 조건**
- 원주문이 존재하지 않는 경우
- 원주문의 상태가 `취소완료`가 아닌 경우

**출고 진행 중인 경우**
- 물류에서 출고 중인 경우(출하대기, 출고완료)
- 주문 상태를 `취소요청`으로 변경합니다.

**결제 취소인 경우**
- 물류 진행이 아닌 결제만 진행된 경우
- 원 주문 상태를 `취소완료`으로 변경합니다.

**주문 상태 변경 이력 생성**
- 2가지 경우에 따라 변경된 이력을 기록합니다.
- '주문확정', '출고요청', '출고준비중' -> '취소완료'
- '출하대기', '출고완료' -> '취소요청'
