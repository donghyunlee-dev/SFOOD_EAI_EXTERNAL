# 📦 납기예정일 설정 정의

## 📝 개요
> 외부 시스템(External)에서 수집한 주문의 **배송 납기예정일**을 계산하는 기준을 정의합니다.  
> 이는 WMS(물류 관리 시스템)에서 원활한 물류 처리를 위해, 주문 조건에 따라 납기예정일을 정확하게 결정하여 전달하는 과정입니다.

---

## 🎯 주문 대상 조건

- **온라인몰 주문**  
  리테일 주문의 경우 고객이 직접 납기예정일을 지정하므로 계산 대상에서 제외합니다.
   

- **메디쏠라 스케줄 정기 배송 주문**  
  해당 주문은 납기예정일을 먼저 계산한 뒤, 해당 날짜에 맞춰 주문이 생성되므로 계산 대상에서 제외합니다.

---

## ⚙️ 납기예정일 설정 방식

### 1️⃣ 주문일시 결정
기본적으로 **주문일시**는 정상적으로 연동된 온라인몰 주문이 결제 완료된 시점을 기준으로 합니다.   
결제 시간이 마감시간을 초과하여 수집이 안되는 경우가 있어 **[결제일시]**를 주문일시로 판단합니다.   
ex) 에쓰푸드몰 주문 시간 : 11:19:45, 결제 시간 : 11:20:25 (마감시간 이후)  
   

고도몰의 입금대기 주문은 결제일시가 없기 때문에 주문일시를 기준으로 설정합니다.   
 
   
- 예외 상황
 1. **수집 시간 이후 결제 완료된 주문**  
    → OMS 주문 **생성일시**를 기준으로 설정
   

 2. **입금대기 상태(고도몰)에서 다음 날 이후 결제 완료된 주문**  
    → 결제 완료 시 OMS 주문 상태가 `[주문확정]`으로 변경되며, **수정일시**를 기준으로 납기예정일 재설정

```
 **예외 주문일시 처리 규칙**  
 생성일시 = 수정일시 = 납기예정일 계산 주문일시 (현재시간)
```
---

### 2️⃣ 마감시간 확인
주문 시간과 거래처의 마감시간을 비교합니다.
 - 거래처의 마감시간이 설정되어 있지 않으면 기본값은 **17:00**입니다.
```
[마감시간 이후 여부 확인]
주문시간 > 마감시간 Y, 주문 시간 < 마감시간 N  
```

### 3️⃣ 납기예정일 설정 규칙

#### 📌 고도몰 & 사방넷
| **주문일**     | **마감시간 이내** | **마감시간 이후** |
|-------------|-------------|-------------|
| 월 ~ 목요일   | 주문일 + 1     | 주문일 + 2     |
| 금요일       | 주문일 + 1     | 주문일 + 4     |
| 토요일       | 주문일 + 3     | 주문일 + 3     |
| 일요일       | 주문일 + 2     | 주문일 + 2     |
